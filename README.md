# NLE Review Quiz PWA

This folder is a Progressive Web App version of the supplied NLE Review Quiz.

Files:
- index.html — original quiz app, adapted for PWA installation
- manifest.json — PWA metadata
- sw.js — offline service worker
- icons/ — home-screen icons

To publish it for phone installation, upload this folder to a static HTTPS host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

The quiz data and behavior from the original HTML were preserved.
